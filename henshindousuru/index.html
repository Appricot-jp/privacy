返信どうする？（AI返信・添削メーカー）

最終更新日: 2026年7月6日

本プライバシーポリシーは、「返信どうする？」（以下「本アプリ」）におけるユーザー情報の取り扱いについて定めるものです。本アプリをご利用いただく前に、本ポリシーをよくお読みください。

1. 収集する情報

1-1. 入力テキスト

本アプリは、返信文の作成および文章の添削を目的として、ユーザーが入力欄に貼り付け・入力したメッセージ本文（以下「入力テキスト」）を処理します。

1-2. スクリーンショット画像（任意）

「スクショで入力」機能を利用する場合、ユーザーがフォトライブラリから選択した画像を、画像内の文字を読み取る（OCR）目的で処理します。読み取ったテキストのみを入力欄に反映し、画像そのものを本アプリが保存することはありません。

重要: 本アプリはアカウント登録を必要とせず、氏名・メールアドレス・電話番号・位置情報などの個人を直接特定する情報を収集しません。

1-3. 生成結果・履歴

AIが生成した返信・添削の候補、および入力テキストは、履歴として利用できるようユーザーのデバイス内に保存されます。

2. 情報の利用目的

収集した情報は、以下の目的にのみ使用します：

  • 返信・添削の生成: 入力テキストおよびスクリーンショットから読み取ったテキストをAI（OpenAI API）に送信し、返信文の作成・文章の添削を行います
  • 履歴の管理: 過去の生成結果をデバイス上に保存し、後から見返し・再コピーできるようにします
入力テキストや画像を、広告ターゲティングやユーザー識別など、返信・添削の生成以外の目的に使用することは一切ありません。

3. 第三者への提供

3-1. OpenAI（AIによる生成・文字認識）

返信・添削の生成および画像の文字認識のため、入力テキストおよび画像データをOpenAI社のAPI（api.openai.com）に送信します。OpenAIはAPIリクエストで送信されたデータをモデルのトレーニングに使用しません（OpenAI API Data Usage Policy に基づく）。送信されたデータはAPI処理完了後、OpenAIのデータ保持ポリシーに従い最大30日間保持された後、削除されます。

3-2. Google AdMob（広告配信）

無料プランでは、Google AdMob SDKを使用して広告を配信します。AdMobは広告配信に必要な情報（デバイス識別子等）を収集する場合がありますが、入力テキストや画像がAdMobと共有されることはありません。

3-3. Apple（アプリ内課金）

プレミアムプランの購入処理は、AppleのStoreKitを通じて行われます。課金に関する情報はAppleが管理します。

上記以外の第三者に入力テキスト・画像を共有・販売・提供することはありません。

4. データの保存場所

  • 入力テキスト・生成結果（履歴）: ユーザーのデバイス内にのみ保存されます。iCloudへの自動同期は行いません。
  • スクリーンショット画像: 文字認識のためにのみ一時的に処理し、本アプリ内に保存しません。
  • サーバー: 本アプリは独自のサーバーを持たず、ユーザーデータをサーバーに恒久的に保存することはありません。

5. データの保持期間

  • デバイス上の履歴: ユーザーが手動で削除するまで保持されます（一定件数を超えると古いものから自動的に整理されます）。アプリ内の履歴機能から削除できます。
  • OpenAI APIに送信されたデータ: OpenAIのデータ保持ポリシーに従い、APIリクエスト処理後、最大30日間保持された後に削除されます。
  • アプリの削除: アプリを削除すると、デバイス上のすべての履歴データが完全に削除されます。

6. ユーザーの権利

ユーザーは以下の権利を有します：

  • 履歴の閲覧: アプリ内の履歴機能で、過去の生成結果を閲覧できます
  • データの削除: アプリ内から履歴を削除できます
  • 写真アクセスの拒否: フォトライブラリへのアクセス許可をいつでも拒否・取り消すことができます（iOS設定から変更可能）

7. セキュリティ

本アプリは以下のセキュリティ対策を講じています：

  • API通信はHTTPS（TLS暗号化）により保護されます
  • 履歴データはユーザーのデバイス内にのみ保存され、外部サーバーに恒久的に保存されることはありません

8. 未成年者のプライバシー

本アプリは13歳未満のお子様を対象としておらず、13歳未満のお子様から意図的に情報を収集することはありません。13歳未満のお子様が本アプリを使用していることが判明した場合は、お問い合わせください。

9. プライバシーポリシーの変更

本ポリシーは、法令の変更やサービス内容の変更に伴い、事前の通知なく変更される場合があります。重要な変更がある場合は、アプリ内でお知らせします。最新のポリシーは常にこのページでご確認いただけます。
