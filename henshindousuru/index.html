返信どうする？（AI返信・添削メーカー）

制定日: 2026年7月6日 / 最終更新日: 2026年10月1日

appricot（以下「当社」）は、iOSアプリ「返信どうする？（AI返信・添削メーカー）」（以下「本アプリ」）における利用者情報の取り扱いを、以下のとおり定めます。本アプリをご利用いただく前に、本ポリシーをお読みください。

要点: 入力した文章・スクリーンショットは、返信案の作成と添削のためだけに外部のAI（OpenAI社）へ送信します。当社のサーバには文章・画像・生成結果を保存しません。履歴は端末内にのみ保存されます。アカウント登録は不要で、氏名・メールアドレス・電話番号・位置情報の入力を求めることはありません。

1. AIに送信する情報

  • 入力した文章・スクリーンショット: 返信案の作成・添削・言い回しの調整・画像内の文字の読み取りのために送信します。
  • プロフィール（任意）: 設定画面で登録した会社名・部署・氏名、マッチング用の呼び名と自己紹介は、返信案（署名など）に反映するために送信します。登録しなければ送信されません。
  • 返信の方向・「伝えたいこと」: 返信の方針として、文章と一緒に送信します。

1-1. 送信の経路

  • バージョン2.2以降: 当社の中継サーバ（Cloudflare 上で運用）を経由して OpenAI 社の API に送信します。中継サーバは文章・画像・生成結果を保存しません。サーバのログにも本文や画像は記録しません。
  • バージョン2.1以前: 端末から OpenAI 社の API（api.openai.com）に直接送信します。当社のサーバは経由しません。

いずれの経路でも、OpenAI 社は API で受け取ったデータを AI モデルの学習に使わず、不正利用の監視のために最大30日間保持した後に削除します（法令上の義務がある場合を除く）。詳しくは OpenAI のプライバシーポリシー および API のデータ利用方針をご覧ください。

1-2. 送信前の同意

バージョン2.2以降では、初めて返信・添削・スクリーンショットの読み取りを行う前に、AIへの送信について説明する画面を表示し、同意をいただいてから送信します。同意はいつでも取り消せます（5章）。

2. 端末内に保存する情報

  • 生成履歴: 入力した文章と生成結果は、見返し・再コピーのために端末内にのみ保存します（新しい順に100件まで。超えた分は古いものから自動的に削除します）。iCloud への同期は行いません。
  • プロフィール: 端末内にのみ保存します。
  • スクリーンショット画像: 文字の読み取りのためにのみ一時的に使い、本アプリ内に保存しません。
  • 共有機能で受け取った文章・画像（バージョン2.2以降）: 他のアプリの共有メニューから本アプリに送った文章・画像は、端末内の受け渡し領域に一時的に保存し、本アプリで取り出した時点（または24時間後）に削除します。共有した時点では外部に送信しません。本アプリで取り出して返信・添削を実行したときに、1章のとおり送信します。

3. 利用回数の管理に使う情報（バージョン2.2以降）

中継サーバでは、無料でご利用いただける回数の管理と、不正な大量アクセスの防止のために、次の情報を使います。

  • 匿名の端末ID: 本アプリが端末内で生成するランダムなIDです（端末のキーチェーンに保存するため、アプリを再インストールしても同じ値が使われる場合があります）。1日の利用回数の管理のためにのみ使い、氏名などの個人を特定する情報とは紐付けません。広告やトラッキングには使いません。回数の記録は約2日で自動的に削除されます。
  • IPアドレス: 短時間の大量アクセスを防ぐため、回数・利用量の集計にのみ使います。集計は約2日で自動的に削除されます。
  • 購入情報（プレミアムの方のみ）: プレミアムの利用枠を確認するため、Apple が署名した購入情報（商品・有効期限など）をリクエストごとに送信し、その場で確認します。保存しません。

4. 第三者サービス

4-1. OpenAI（AIによる生成・文字の読み取り）

1章の情報を処理します。

4-2. Google AdMob（広告の表示）

無料プランでは Google AdMob を使って広告を表示します。AdMob は広告の配信に必要な情報（端末やアプリに関する情報など）を取得する場合があり、その取り扱いは Google のプライバシーポリシー に従います。入力した文章・画像・プロフィールを AdMob に渡すことはありません。

4-3. Apple（アプリ内課金）

プレミアムプランの購入は Apple の StoreKit を通じて行われます。当社はクレジットカード情報等を取得しません。

4-4. Cloudflare（中継サーバの運用基盤・バージョン2.2以降）

中継サーバを運用する基盤として利用します。

当社は、上記の委託先・第三者サービスが本ポリシーと同等以上の水準で利用者の情報を保護していることを、各社の規約・方針により確認したうえで利用します。法令に基づく場合を除き、利用者の情報を第三者に販売・提供しません。入力した文章や画像を、広告のターゲティングや利用者の識別など、返信・添削の作成以外の目的に使うことはありません。

5. 同意の取り消し・データの削除

  • 同意の取り消し（バージョン2.2以降）: アプリの「設定（歯車）＞ このアプリについて ＞ AIの利用とデータの扱い」の「同意を取り消す」から、いつでも取り消せます。取り消した後は、再び同意するまで AI への送信を行いません。
  • 端末内のデータ: 生成履歴は履歴画面から、プロフィールは設定画面から削除できます。アプリを削除すると、履歴・プロフィールなど端末内のデータは削除されます。
  • 当社サーバのデータ: 文章・画像・生成結果は保存していません。回数の記録（匿名の端末ID・IPアドレスの集計）は約2日で自動的に削除されます。それより前の削除や、その他の開示・削除のご請求は、下記のお問い合わせ先までご連絡ください。
  • OpenAI 社が保持するデータ: 1章のとおり最大30日間で削除されます。
  • 写真へのアクセス: フォトライブラリへのアクセスは、iOS の「設定」からいつでも拒否・取り消しできます。

6. 安全管理

通信はすべて HTTPS（TLS）で暗号化します。

7. 対象年齢

本アプリは13歳未満の方を対象としておらず、13歳未満の方から意図的に情報を集めることはありません。13歳未満の方が本アプリを利用していることが分かった場合は、お問い合わせください。
