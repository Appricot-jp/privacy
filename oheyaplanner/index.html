プライバシーポリシー

お部屋プランナー

最終更新日: 2026年11月16日

本プライバシーポリシーは、iOSアプリ「お部屋プランナー」（以下「本アプリ」）における利用者の情報の取り扱いについて定めるものです。本アプリは Appricot（運営者：Gota Kawano、以下「当社」）が提供します。

1. おしゃれ相談で送る情報

「部屋をおしゃれにする」（おしゃれ相談）で提案を作るときだけ、次の情報を送信します。初めて送る前に、アプリの中で確認します。この同意は、アプリの設定からいつでも取り消せます。

  • 送るもの: 利用者がえらんだ部屋の写真1枚（端末で長辺1024ピクセルに縮め、撮影場所などの付帯情報を消したもの）と、質問への答え（なりたい雰囲気・予算などの選択肢）
  • 送らないもの: 名前・連絡先・自由に書いた文。部屋の図・家具の記録
  • 送り先: 当社のサーバー（Cloudflare Workers）を経由して、Google の Gemini API（有料の利用枠）に送り、提案の文を作ります
  • 目的: 部屋をおしゃれにするためのやること・足すとよい家具の提案を作るためだけに使います
当社のサーバーは写真と答えを保存しません（中継と回数の管理だけを行います）。写真に人や個人の情報が写っていないか、送る前にご確認ください。写真を広告・人の識別・顔認識など、提案を作る以外の目的に使うことはありません。

2. 寸法の読み取りに使う写真・スクリーンショット

「家具が置けるか確かめる」で、商品ページのスクリーンショットなどから寸法を読むときは、この端末の中で文字を読み取るだけです（Apple の Vision フレームワーク）。画像は送信せず、読み取ったあとは保存しません。

3. 端末に保存する情報

部屋の寸法・家具の配置・相談の写真と提案は、この端末の中にだけ保存します。当社は受け取りません。iPhone・iPad のバックアップの対象になります。アプリの設定の「すべての部屋と提案を削除」で、写真を含めて消せます。アプリを削除しても消えます。

4. 回数の管理と不正の防止

1日の相談の回数を数え、不正な利用を防ぐため、相談のたびに Apple の App Attest の鍵の ID と確認用のデータを当社のサーバーに送ります（初回に一度、鍵の登録のための情報も送ります）。この ID は利用者の名前やメールアドレスとは結び付けません。

当社のサーバーに残るもの期間
その日の相談の回数（鍵の ID のハッシュごと）日本時間0時に作り直し、前の日の分は約48時間以内に消えます
App Attest の鍵の登録（公開鍵とカウンタ）最後に使ってから400日で消します
同じ相談を二重に数えないための控え（ランダムな依頼番号）10分
動作の記録（日時・回数の種類・かかった時間と費用・鍵の ID のハッシュの先頭8文字）Cloudflare の記録の保存期間（写真・答え・提案の文・IP アドレスは記録しません）

5. 第三者への提供

5-1. Google（Gemini API）

「1」の写真と答えを、当社のサーバーを経由して Google LLC の Gemini API に送ります。当社は有料の利用枠を使っており、Google は有料の利用枠で送られた内容を製品の改善に使いません。Google は、禁止された使い方の検出・防止と法令上の開示のため、送られた内容を限られた期間記録します（Gemini API 追加利用規約、2026年3月23日発効の版で確認）。

5-2. Google AdMob（広告）

プラスを購入していない場合、おしゃれ相談で提案を作る前に、利用者がボタンを押して見る動画広告（リワード広告）を Google AdMob で表示します。ほかの画面に広告は出しません。広告の配信のため、本アプリに組み込んだ AdMob SDK が次の情報を Google に送信します。写真・答え・提案・部屋の記録は AdMob と共有しません。追跡（App Tracking Transparency）の許可は求めません。そのため、広告用の識別子（IDFA）は使われません。

  • おおよその位置情報（IP アドレスから推定）
  • デバイスの識別子
  • 広告データ（表示・タップした広告など）・アプリの操作データ
  • クラッシュ・パフォーマンスなどの診断データ

AdMob による情報の取り扱いは Google のプライバシーポリシーと Google のサービスを使用するサイトやアプリから収集した情報の Google による使用をご確認ください。

5-3. Apple（購入）

「プラス」（買い切り）の購入は Apple の App Store が処理します。当社は支払いの情報を受け取りません。

5-4. 外国にある第三者への提供

「5-1」のとおり、写真と答えを外国にある第三者である米国の Google LLC に提供します。個人情報の保護に関する法律に基づき、次をお知らせします。

  • 提供先の国: アメリカ合衆国（Google LLC。内容は Google が施設を持つ国で一時的に保存・処理されることがあります）
  • その国の個人情報の保護に関する制度: 米国には日本の個人情報保護法に相当する連邦の包括的な法律はなく、分野ごとの連邦法や州法で個人情報が保護されています。詳しくは個人情報保護委員会の情報をご覧ください。
  • 提供先が講じている措置: 有料の利用枠で送られた内容を製品の改善に使わず、記録は不正利用の検出などのための限られた期間に限ります。データ処理に関する追加条項に従って処理されます。

6. 外部のサイト

提案の「お店で探す」は、利用者が押したときに Safari で通販サイトの検索ページを開くだけです。開いたサイトでの情報の取り扱いは、そのサイトのポリシーに従います。本アプリは、どの商品を押したかを記録・送信しません。

7. 同意の取り消し・削除・お問い合わせ

  • 写真を送る同意は、アプリの設定の「送信の同意を取り消す」で取り消せます（次に相談するときに、もう一度確認します）。
  • 端末の記録は、アプリの設定の「すべての部屋と提案を削除」で消せます。
  • 当社のサーバーに残る回数の記録の削除など、本ポリシーに関するお問い合わせは contact@appricot.jp までご連絡ください。

8. 改定

本ポリシーを変更するときは、このページに掲示し、最終更新日を改めます。
